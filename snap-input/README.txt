Survivable Input Snap (Geode mod) - v0.1

1. Rozpakuj ten folder.
2. Zmien "id" i "developer" w mod.json.
3. Uruchom build.bat (przy pierwszym uruchomieniu zainstaluje narzedzia,
   potem trzeba odpalic go jeszcze raz w nowym oknie).
4. Gotowy plik .geode bedzie w folderze build.

UWAGA: funkcja stepOnce() w src/main.cpp jest pusta. Bez jej
uzupelnienia mod sie zbuduje, ale nic nie robi.
Mod dziala tylko w practice mode.
